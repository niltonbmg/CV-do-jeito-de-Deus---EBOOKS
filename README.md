# Do Rei Soluções — Portal do Empreendedor

Portal estático para vender soluções (tecnologia, escritório, gestão, marketing, formalização) e conhecimento (e-books, cursos, mentorias).

- `index.html` — estrutura do portal
- `styles.css` — visual
- `app.js` — áreas, produtos, artigos, carrinho e pedidos via WhatsApp

## Personalizar
Em `app.js`: troque `WHATSAPP` pelo seu número e edite as listas `AREAS`, `PRODUTOS` e `ARTIGOS`.

## Publicar
Abra `index.html` no navegador, ou ative o GitHub Pages (Settings → Pages → branch principal).
